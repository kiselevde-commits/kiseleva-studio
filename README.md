# Kiseleva — Студия дизайна интерьеров

Премиальный одностраничный лендинг студии дизайна интерьеров. Стиль — *Quiet Luxury*: тёплый молочный фон, глубокий графитовый текст, приглушённое золото в акцентах и много «воздуха».

## Возможности

- **Адаптивная вёрстка** (Mobile First) — корректно отображается на смартфонах, планшетах и десктопе.
- **Хедер при скролле** — прозрачный вверху и с фоном + затемнением после прокрутки.
- **Мобильное меню** — выезжающая панель с анимацией бургера в «крестик».
- **Reveal-анимации** — плавное появление секций через `IntersectionObserver`.
- **Фильтр портфолио** — категории: жилые, коммерческие, общественные.
- **Bento-сетка** реализованных проектов.
- **Слайдер отзывов** — автопрокрутка, точки навигации, пауза при наведении.
- **Калькулятор стоимости** — расчёт по площади со ставкой за м².
- **Валидация формы заявки** — проверка имени и телефона, сообщение об успехе.
- **Кнопка «наверх»** — появляется при прокрутке.

## Технологический стек

- **HTML5** — семантическая вёрстка.
- **Tailwind CSS** — подключён через CDN (без сборщиков).
- **Vanilla JavaScript** — без фреймворков, вся логика в [`script.js`](script.js:1).
- **Google Fonts** — Playfair Display (заголовки) и Inter (текст).
- **Иконки** — встроенные inline-SVG.

## Запуск

Проект не требует сборки и зависимостей.

Откройте [`index.html`](index.html:1) в браузере двойным кликом — или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8080

# Node.js (если установлен npx)
npx serve .
```

Затем перейдите на [http://localhost:8080](http://localhost:8080).
