# Папка для фотографий проектов

Сюда вы кладёте свои фотографии, чтобы они отображались на сайте.

## Как добавить своё фото

1. Скопируйте файл изображения в эту папку (`images/`).
2. Дайте ему простое имя латиницей **без пробелов и русских букв**, например:
   - `project-1.jpg`
   - `living-room.jpg`
   - `kitchen-2.webp`
3. В файле [`index.html`](../index.html) найдите нужную карточку и замените
   `src` картинки на путь `images/ваше-имя.jpg`.

## Пример подключения

Было (демо-фото из интернета):

```html
<img src="https://images.unsplash.com/photo-1618221195710-dd6b41faaea6?auto=format&fit=crop&w=1600&q=80"
     alt="Апартаменты в ЖК Light"
     class="absolute inset-0 w-full h-full object-cover ..." />
```

Стало (ваше локальное фото):

```html
<img src="images/project-1.jpg"
     alt="Апартаменты в ЖК Light"
     class="absolute inset-0 w-full h-full object-cover ..." />
```

> `alt` — это текстовое описание фото (важно для SEO и доступности).
> Меняйте его под смысл снимка.

## Рекомендации по формату

- Формат: `.jpg` для фото, `.webp` — для меньшего размера файла.
- Ширина: 1600–2000 px для больших карточек, 1000 px для маленьких.
- Вес файла: старайтесь держать до 300–500 КБ, чтобы сайт грузился быстро.
